# Sequential Models - RNN & LSTM Analysis

## Project Overview

This project provides a detailed exploration and implementation of sequential neural network architectures, specifically Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks. The primary objective is to analyze sequential/time-series data, address traditional RNN challenges like exploding/vanishing gradients, and demonstrate the superior memory capabilities of LSTMs in capturing long-term dependencies.

## Tasks Covered

The repository covers key tasks in sequential modeling, including:

1. **Data Preprocessing & Sequences**: Formatting time-series or text data into input-output sequence windows and performing feature scaling.
2. **Vanilla RNN Implementation**: Building and training a basic Recurrent Neural Network architecture to establish baseline performance.
3. **Gradient Analysis**: Evaluating model convergence and identifying limitations of standard RNNs (vanishing and exploding gradient issues).
4. **LSTM Architecture Setup**: Implementing Long Short-Term Memory networks to handle long-range temporal patterns effectively using memory cells and gates.
5. **Model Comparison & Evaluation**: Comparing performance metrics (e.g., Loss, Accuracy, MAE/RMSE) between RNN and LSTM models.
6. **Predictions & Visualization**: Visualizing prediction performance against actual data trends over time.

## Technologies Used

* **Language**: Python 3.x
* **Libraries**:
  * `TensorFlow` / `Keras` (or `PyTorch`): Model building, training, and evaluation.
  * `Pandas`: Data manipulation and preprocessing.
  * `NumPy`: Array operations and sequence transformation.
  * `Matplotlib` & `Seaborn`: Visualizing training loss curves and sequential predictions.

## Files in the Repository

* `Sequential_Models_RNN_LSTM.ipynb`: Main Jupyter notebook containing the complete implementation, training loops, and comparisons.
* `README.md`: Overview and documentation for the repository.
* `Dataset/`: Directory containing input data used for sequence modeling.
